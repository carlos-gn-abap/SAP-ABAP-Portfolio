# SAP ABAP Portfolio

A collection of SAP Classic ABAP projects developed in SAP GUI, focused on backend development, business logic, data modeling and reporting.

## Technologies

- Classic ABAP and Object-Oriented ABAP.
- SAP GUI and Module Pool (Dynpros).
- Open SQL.
- ALV Reports.
- SAP Data Dictionary (DDIC).
- Modularization techniques.
- Debugging.

## Projects

### 1. Order Management Transaction

A business transaction for managing orders, developed using Module Pool (Dynpros) and combining classic and object-oriented ABAP. Includes custom Z tables for order headers and items, business validations, item management, Open SQL queries and ALV reports.

### 2. Employee Management Transactions

A set of transactions for employee registration and maintenance, including employee lookup, data creation, modification and deletion. Developed using Module Pool (Dynpros), custom Z tables, Open SQL queries, business validations and screen navigation.

### 3. ALV Reports

Reports featuring selection screens, database data retrieval through Open SQL and structured output using ALV.
